# DATABASE — Стратегия хранения данных

> **Архитектурный выбор:** Разделение транзакционных метаданных и высокочастотных временных рядов.

---

## 1. Схема многоуровневого хранения (Tiered Storage)

```
┌─────────────────────────────────────────────────────────────┐
│                 Таймсерии (High Volume)                     │
│                 TimescaleDB / ClickHouse                    │
│  - Свечи (1m, 5m, 1h, 1d)                                   │
│  - Открытый интерес (snapshots раз в 1m-5m)                │
│  - Ставки фандинга (snapshots раз в 1m-8h)                  │
│  - Поток подтвержденных ликвидаций                          │
└─────────────────────────────────────────────────────────────┘
                               ▲
                               │
┌─────────────────────────────────────────────────────────────┐
│               Реляционные данные (Relational)               │
│                         PostgreSQL                          │
│  - Профили пользователей и подписки                         │
│  - Настройки алертов и списки наблюдения (Watchlist)        │
│  - Записи торгового журнала (Trade Journal)                 │
│  - Формулы стратегий (Strategy Definitions)                 │
└─────────────────────────────────────────────────────────────┘
                               ▲
                               │
┌─────────────────────────────────────────────────────────────┐
│                    Кэш реального времени                    │
│                            Redis                            │
│  - Текущие актуальные тикеры                                │
│  - Очередь последних событий радара                         │
│  - WebSocket Pub/Sub для рассылки клиентам                  │
└─────────────────────────────────────────────────────────────┘
```

> **Предостережение от ошибки масштаба:**  
> Высокочастотные рыночные данные никогда не пишутся в один плоский файл SQLite в продакшене. На Этапе 1 фронтенд использует строго детерминированный in-memory Demo Store, не привязанный к конкретной СУБД.
