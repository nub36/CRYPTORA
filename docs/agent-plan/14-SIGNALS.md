> **Статус:** Выполнен (v0.6.0)  
> ⚠️ **ИНВАРИАНТ:** **CRYPTORA DOES NOT EXECUTE TRADES.**  
> Аналитические сетапы — это структурированные рыночные наблюдения, а не торговые приказы или финансовые рекомендации. Терминал фиксирует гипотезы в неизменяемом журнале для проверки качества аналитики, исключая торговлю в один клик или копитрейдинг.

## 1. Выполненные задачи

### 1.1. Неизменяемый журнал аудита сетапов (`SignalsAuditLedger`)
- Файл: `src/services/signals/SignalsAuditLedger.ts`
- Формализованная структура аналитического сетапа (`AnalyticalSetup`):
  - Диапазон входа (`entryZone`);
  - Уровень отмены / Stop Loss (`invalidationLevel`);
  - Целевые уровни (`targets`);
  - Соотношение риск/прибыль (`riskRewardRatio`);
  - Обязательный список подтверждающих наблюдений (`confirmingFactors`);
  - Обязательный список опровергающих факторов и рисков (`invalidationFactors`);
  - Криптографический хэш неизменяемости (`auditHash`, цепочка SHA-256).
- Метод верификации целостности цепочки хэшей (`verifyIntegrity`) для защиты от изменения задним числом.
- Прозрачный расчет результативности без ошибки выжившего:
  $$\text{Accuracy Rate \%} = \frac{\text{TargetReached}}{\text{TargetReached} + \text{Invalidated}} \times 100\%$$

### 1.2. Интеграция с UI

  - Фильтры по статусам (`Все`, `Активные`, `Цель достигнута`, `Инвалидированы`);
  - Отображение хэша SHA-256 и факторов за/против по каждому сетапу.
