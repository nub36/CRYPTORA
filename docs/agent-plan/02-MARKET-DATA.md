# 02-MARKET-DATA — Этап 2: Подключение спотовых рыночных данных

> **Статус:** Запланирован к реализации после Этапа 1

---

## 1. Задачи
- Разработка модуля Collector для опроса публичных REST API (Binance, Bybit).
- Нормализация тикеров и свечей в канонический формат Zod.
- Реализация `LiveMarketDataProvider` на клиенте с возможностью переключения Demo/Live.
- Кэширование запросов для предотвращения превышения Rate Limits.

## 2. Критерии приемки
- Реальные цены и объемы топ-20 активов.
- Переключение провайдера в конфигурации без изменения верстки страниц.
