# 11-HISTORICAL-DATA — Этап 11: Хранилище временных рядов

> **Статус:** Выполнен (v0.6.0)  
> ⚠️ **ИНВАРИАНТ:** **CRYPTORA DOES NOT EXECUTE TRADES.**  
> Хранилище временных рядов предназначено исключительно для сохранения исторических OHLCV серий, дедупликации данных и передачи массивов в движок бэктестинга и аналитические графики.

---

## 1. Выполненные задачи

### 1.1. Репозиторий временных рядов (`TimeSeriesRepository`)
- Файл: `src/services/storage/TimeSeriesRepository.ts`
- Интерфейс `TimeSeriesRepository` для сохранения, выборки и валидации свечей.
- In-memory реализация `MemoryTimeSeriesRepository` с автоматической сортировкой и дедупликацией по `timestamp`.
- Алгоритм детекции временных разрывов (`detectGaps`):
  - Вычисление ожидаемого интервала между барами;
  - Поиск пропущенных сегментов в исторических данных.
