# RULES — Инварианты и архитектурные запреты

> **Обязательно для соблюдения всеми AI-агентами**

---

1. **Не пытаться делать всё одним проходом:**  
   Строго следовать текущему этапу. Запрещено перескакивать на бэктестинг, подключение биржевых API или AI на этапе визуального фундамента.
2. **Маркировка демонстрационных данных:**  
   На этапе 1 любые мок-данные обязаны иметь явное указание `«Демонстрационные данные»` в UI, чтобы пользователь никогда не принял демо-котировки за реальные.
3. **Никакого `Math.random()` в котировках:**  
   Все данные детерминированы. Не создавать дергающиеся случайные числа ради псевдо-живости.
4. **Изоляция источника данных через интерфейс:**  
   Компоненты UI взаимодействуют с данными исключительно через абстракцию `MarketDataProvider`.
5. **Сайт НЕ биржа:**  
   Никакого хранения приватных ключей, депозитов или отправки реальных торговых ордеров.
6. **AI — только финальный слой объяснения:**  
   Никакого вычисления цен, индикаторов или ликвидаций языковой моделью.
7. **Кодекс завершения работы:**  
   Обязательный запуск `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`, фиксация статуса в `STATUS.md` и осмысленный commit.
