# 01-VISUAL-FOUNDATION — Этап 1: Визуальный терминал и Demo-данные

> **Статус:** В реализации  
> **Цель этапа:** Создать полностью функционирующий визуальный терминал высокой плотности, по которому можно ходить, переключать режимы, графики, фильтры и оценивать UX на детерминированных демонстрационных данных.

---

## 1. Задачи этапа
1. Настроить проектную структуру, конфигурацию сборки (Vite, TypeScript, Tailwind CSS).
2. Разработать строгие интерфейсы данных и детерминированный Demo-слой.
3. Реализовать терминальные страницы:
   - Overview (Главный командный центр)
   - Market (Таблица активов с сортировкой, фильтрацией и спарклайнами)
   - Coin Detail (Свечной график, деривативы, индикаторы, стакан)
   - Futures (Сводка деривативов, открытый интерес, фандинг, базис)
   - Liquidations (Сводка Long/Short, таймлайн, фактические ликвидации vs модель)
   - Screener (Работающие фильтры по детерминированному датасету)
   - Market Radar (Лента аномалий по степеням важности)
   - Heatmaps (Плитки рынка по разным метрикам)
   - Tools (Работающие калькуляторы Position Size и PnL)
   - Strategies & Signals (Честные превью-страницы будущей методологии)
4. Покрыть код юнит-тестами и сквозными E2E-тестами.
5. Обеспечить адаптивность для экранов 390, 768, 1024, 1440, 1920.

---

## 2. Критерии приемки
- 100% маршрутов открываются без ошибок.
- Наличие явной маркировки «Демонстрационные данные».
- Работающая сортировка и фильтрация в таблицах и скринере.
- Прохождение `npm run typecheck`, `npm test`, `npm run build`, `npm run test:e2e`.
