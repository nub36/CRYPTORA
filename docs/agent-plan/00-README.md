# AGENT PLAN — Дорожная карта и регламент AI-агентов

> **Каталог пошагового развития CRYPTORA**

---

## 1. Назначение каталога

В этой папке зафиксирован подробный операционный план реализации терминала CRYPTORA по этапам. Каждый документ описывает границы задач, критерии приемки, тесты и ограничения соответствующего этапа.

---

## 2. Порядок чтения для агента

Каждый агент начинает работу со строгого соблюдения последовательности:
1. `AGENTS.md` в корне репозитория.
2. `docs/agent-plan/00-README.md` (этот файл).
3. `docs/agent-plan/STATUS.md` (**ЕДИНСТВЕННАЯ ТОЧКА ОСТАНОВКИ** — текущий статус, коммиты, результаты тестов).
4. `docs/agent-plan/RULES.md` (инварианты и архитектурные запреты).
5. Документ текущего этапа (например, `01-VISUAL-FOUNDATION.md`).
6. Документы подсистемы в `docs/`.
7. Существующий код и тесты.

---
