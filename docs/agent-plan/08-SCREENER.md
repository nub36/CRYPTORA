---

## 1. Выполненные задачи

### 1.1. Движок скринера (`ScreenerEngine`)
- Файл: `src/services/screener/ScreenerEngine.ts`
- Мультифакторная композитная фильтрация:
  - Фильтр по категории актива (`L1`, `DeFi`, `L2`, `AI`);
  - Границы суточного изменения цены (`minPriceChange24h`, `maxPriceChange24h`);
  - Пороги спотового объема (`minVolume24h`) и рыночной капитализации;
  - Пороги осциллятора перекупленности/перепроданности RSI(14);
  - Фильтр ставки финансирования деривативов (positive, negative, squeeze watch);
  - Фильтр динамики открытого интереса (`minOpenInterestDelta24h`).

### 1.2. Системные и пользовательские пресеты
- Встроенные системные пресеты:
  - `oversold_rsi`: RSI(14) < 30;
  - `volume_leaders`: суточный объем > $500M;
  - `short_squeeze`: отрицательный фандинг < -0.005% при росте цены;
  - `oi_breakout`: приток открытого интереса > 8%;
  - `ai_sector`: активы сектора Artificial Intelligence.
- Поддержка сохранения, обновления и загрузки пользовательских пресетов.

### 1.3. Интеграция с UI
- Страница `src/pages/ScreenerPage.tsx` дополнена кнопками быстрых пресетов (`Top Gainers`, `Short Squeeze`, `High Volume`, `AI Sector`).
