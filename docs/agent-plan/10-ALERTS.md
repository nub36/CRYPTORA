# 10-ALERTS — Этап 10: Распределенная система алертов

> **Статус:** Выполнен (движок v0.6.0; фактическая оценка, история и каналы Telegram/Webhook — v0.8.23)  
> ⚠️ **ИНВАРИАНТ:** **CRYPTORA DOES NOT EXECUTE TRADES.**  
> Система алертов отправляет уведомления о достижении ценовых порогов, изменениях фандинга и резких всплесках открытого интереса. Алерты служат только для привлечения внимания пользователя и не отправляют торговые ордера на биржи.

---

## 1. Выполненные задачи

### 1.1. Движок оценки алертов (`AlertService`)
- Файл: `src/services/alerts/AlertService.ts`
- Поддерживаемые условия:
  - `PRICE_ABOVE`: цена поднялась выше заданного уровня;
  - `PRICE_BELOW`: цена опустилась ниже заданного уровня;
  - `CHANGE_24H_ABOVE`: суточный прирост превысил порог;
  - `CHANGE_24H_BELOW`: суточное падение превысило порог;
  - `FUNDING_EXTREME`: модуль ставки фандинга превысил пороговое значение.
- Каналы доставки: `IN_APP`, `TELEGRAM`, `WEBHOOK`.
- Защита от дребезга (cooldown suppression) с настраиваемым интервалом затухания повторных уведомлений.
- Журнал истории сработавших событий (`getTriggeredHistory`).

### 1.2. Интеграция с UI и фактическая оценка (v0.8.23)
- `alertEvaluator.ts` — чистые функции оценки пользовательских правил (`ABOVE`, `BELOW`, `FUNDING_EXTREME`, `OI_SPIKE`), cooldown, пауза.
- `MarketDataContext` — оценка на каждом WS-тике `ticker:*` и по REST-фандингу (60 с); история срабатываний; лимит тарифа.
- `deliveryChannels.ts` + `AlertDispatcher.ts` — В приложении, браузерные Notification, Telegram Bot API, Webhook; журнал доставки со
  статусами `DELIVERED` / `SENT_UNCONFIRMED` / `FAILED` / `SKIPPED`. Конфигурация каналов — только в localStorage пользователя.
- `AlertsModal.tsx` — вкладки Правила / История / Каналы; без демо-подписей и фиктивных правил.
- Ограничение: `OI_SPIKE` пока без фактического источника Δ OI 1ч — правило не оценивается (указано в UI). Историческая замечание:
  `AlertService.ts` (v0.6.0) остаётся как автономный движок с собственными типами правил; UI использует `alertEvaluator`.
