# SCREENER — Архитектура и фильтры крипто-скринера

> **Назначение:** Высокопроизводительный отбор активов по множеству рыночных и деривативных критериев.

---

## 1. Параметры фильтрации

Скринер CRYPTORA объединяет спотовые и деривативные метрики:

| Параметр | Описание | Границы/Тип |
|---|---|---|
| **Price Change %** | Изменение цены за выбранный интервал (1h, 24h, 7d) | Min / Max диапазон |
| **24h Volume** | Общий суточный объем торгов | Порог от $1M до $10B+ |
| **Open Interest ($)** | Суммарный открытый интерес | Порог от $500K до $5B+ |
| **OI Change (24h %)** | Динамика открытого интереса | Выявление притока нового капитала |
| **Funding Rate** | Текущая ставка финансирования бессрочного контракта | Все / Только >0 / Только <0 / Экстремумы |
| **RSI-14** | Индекс относительной силы | Диапазон 0–100 (например, <30 для перепроданности) |
| **Market Cap** | Рыночная капитализация | Large Cap, Mid Cap, Small Cap |
| **Sector / Category** | Секторная принадлежность | L1, DeFi, L2, AI, Meme |

---

## 2. Быстрые пресеты (Presets)

1. **Volume Breakout Gainers:** Price Change 24h > 5% И Volume 24h > $50M.
2. **Oversold RSI < 30:** RSI-14 < 30 (потенциал для технического отскока или сильный нисходящий тренд).
3. **Short Squeeze Candidates:** Funding Rate < -0.02% И OI Change 24h > +4%.
4. **Institutional OI Surge:** OI Change 24h > +7% при положительном ценовом импульсе.
