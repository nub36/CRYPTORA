## 3. Что подтверждено, что нет

**Подтверждено автоматикой (в песочнице):** типизация, сборка, все unit/e2e, детерминизм архива стратегий, парность реранов с
историческими артефактами, скриншот-QA 7 ширин × 2 темы (`screenshots/polish-e/`, gitignored).

**UNVERIFIED (песочница без внешней сети):** реальный приём кадров Bybit/OKX; доставка в Telegram/webhook; реальные ответы Binance/KuCoin
на текущих ключах API (проверялись только на фикстурах формата и моках). Всё это требует прогона на VPS или в браузере владельца.

**Осознанно не реализовано:** серверная часть (все истории/настройки — в браузере), LLM-объяснения (AI-брифинг — шаблоны), биллинг, News/Articles и рекламные слоты (scope владельца),
он-чейн/TVL/календарь-провайдеры.

## 4. Известные долги и риски

1. **Разрыв с production** — 20 версий недеплоено; UX-цикл A–E, архив стратегий, темы, алерты, Bybit/OKX пользователи не видят.
2. `DerivativesEngine`: единственная остаточная эвристика — ликвидации 24ч при недоступном потоке (помечена `EST.`). Модельных
   констант в LIVE-провайдере не осталось.
3. Статических страниц не осталось: ecosystem → DeFiLlama v0.8.30, onchain → mempool.space v0.8.31, calendar → Binance v0.8.32, signals → пустой реестр v0.8.33. Живые ответы внешних API UNVERIFIED из песочницы — проверить при первом запуске в проде. CSP production-сервера для этих хостов открыт в v0.8.35 (до этого заблокировал бы их). LIVE-ветка отображения этих трёх страниц проверена стендом `scripts/qa-reference-pages-fixture.mjs` (подмена ответов `page.setRequestInterception` только в браузере проверки, по контракту API): вёрстка и маппинг полей корректны на 390/1440.
4. `AlertService.ts` (v0.6.0) — автономный движок с собственными типами; UI использует `alertEvaluator`. Дубликат стоит удалить или объединить.
5. `package-lock.json` хранит `version 0.8.8` (исторически не обновлялся) — косметика.
6. Чанк сборки > 500 kB — предупреждение Vite; code-splitting страниц не делался.
