# DERIVATIVES — Аналитика криптовалютных деривативов

> **Область:** Бессрочные контракты (Perpetual Swaps), фьючерсы с экспирацией, Open Interest, Funding Rate, Базис.

---

## 1. Ключевые концепции и метрики

### 1.1. Открытый интерес (Open Interest, OI)
- Представляет собой суммарную стоимость всех активных (не экспирированных и не ликвидированных) позиций лонг и шорт.
- **Взаимосвязь цены и OI:**
  - Цена растет + OI растет: приток новых денег в рынок, подтверждение бычьего тренда (агрессивный Long).
  - Цена падает + OI растет: приток новых денег в короткие позиции, агрессивный Short.
  - Цена растет + OI падает: рост за счет закрытия шортов (Short Covering), потенциальная слабость тренда.
  - Цена падает + OI падает: ликвидации лонгов и закрытие позиций (Long Squeeze), признак капитуляции.

### 1.2. Ставка финансирования (Funding Rate)
- Периодический платеж между держателями длинных и коротких позиций.
- Если ставка > 0: покупатели (Long) платят продавцам (Short). Рынок перегрет в сторону роста.
- Если ставка < 0: продавцы (Short) платят покупателям (Long). Высокая вероятность шорт-сквиза при нарастании импульса.
- **Экстремумы фандинга:** Ставки выше +0.05% за 8h или ниже -0.05% за 8h сигнализируют о сильном дисбалансе позиционирования.

### 1.3. Базис (Basis) и спред
- Разница между ценой дериватива ($P_{perp}$ или $P_{quarterly}$) и спотовой индексной ценой ($P_{spot}$):
  $$Basis = \frac{P_{perp} - P_{spot}}{P_{spot}} \times 100\%$$
- Контанго ($Basis > 0$): фьючерс дороже спота (типичное бычье состояние).
- Бэквордация ($Basis < 0$): фьючерс дешевле спота (медвежье напряжение или дефицит спотовой ликвидности).

## 2. Витрина контракта `/futures/:symbol` (2026-09-29)

Полный контракт презентации описан в `docs/INSTRUMENT_DETAIL_PAGES.md`; здесь —
только то, что касается самих деривативных метрик.

### 2.1. Состав блока «Деривативы»

| Метрика | Источник USD-M | Поведение при отсутствии |
|---|---|---|
| Mark / Index | `GET /fapi/v1/premiumIndex` | «Нет данных» |
| Базис % | `(mark − index) / index × 100` (формула §1.3, не менялась) | «Нет данных» |
| Фандинг 8ч | `lastFundingRate` | «Нет данных» |
| Фандинг APR | `fundingRate × 3 × 365` (`DerivativesEngine`) | «Нет данных» |
| Следующий фандинг | `nextFundingTime` → «через 3ч 12м» | «Нет данных» |
| Открытый интерес | `GET /fapi/v1/openInterest` | «Нет данных» |
| OI Δ1ч / Δ24ч | `GET /futures/data/openInterestHist` | **«Нет данных», при этом текущий OI остаётся виден** |
| Объём фьючерса 24ч | `GET /fapi/v1/ticker/24hr` | «Нет данных» |

Спотовая страница показывает тот же блок в варианте `compact` (mark/index,
фандинг APR, OI Δ1ч) — как справку по связанному контракту, с явной пометкой
источника USD-M.

### 2.2. Честность OI-дельт

`openInterestHist` Binance отдаёт историю не для всех контрактов. Раньше это
приводило к соблазну «дорисовать» 0% или спрятать сам OI. Правило: **текущий OI
показывается всегда, когда он получен; отсутствует только дельта.**
`openInterestChangeSource: 'UNAVAILABLE'` → в UI «Нет данных», бейдж
`OiDeltaBadge` не рендерится. Закреплено тестом
`tests/unit/futuresContractPage.test.tsx` («keeps the current open interest while
the OI delta is honestly «Нет данных»»).

### 2.3. Стакан контракта

`GET /fapi/v1/depth` (50 уровней) через same-origin gateway. Спотовая книга
(`/api/v3/depth`) для фьючерсной страницы недоступна: маршрута нет в allowlist,
а провайдер резолвит символ контракта через активную вселенную USD-M. Подробности
и дисциплина запросов — `docs/INSTRUMENT_DETAIL_PAGES.md` §4.

### 2.4. Индикаторы и корреляция

Технические индикаторы (RSI 14, MACD 12/26/9, SMA 20/50/200, Bollinger, ATR 14,
VWAP) на странице контракта считаются **по фьючерсным свечам** тем же
`IndicatorEngine`; формулы не изменялись. Корреляция и бета считаются против
USD-M `BTCUSDT PERP`, а не против спотового BTC; формула не изменялась.
