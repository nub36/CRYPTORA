# CRYPTORA — Не делать (Don't Do List)

> Явный перечень того, что **не** входит в текущую дорожку разработки.
> Обновляется при каждом планировании. Нарушение пункта требует явного одобрения владельца.

---

## Функции и модули

| # | Не делать | Причина |
|---|-----------|---------|
| 1 | AI-рекомендации, AI-торговля, AI-портфель | Вне scope; AI-разбор актива — справочный, не исполнительный |
| 2 | Новостной агрегатор | Нет бесплатного API; не ключевая ценность терминала |
| 3 | Рекламный модуль | Монетизация через спонсорские слоты, не таргетированную рекламу |
| 4 | Серверная копия математики стратегий и «второй» источник сигналов | Сервер ХРАНИТ сигналы (PostgreSQL, миграции 007+009) и отдаёт `GET /api/signals`, но не считает их сам: сетапы публикует только скомпилированное ядро из `src/` (esbuild-бандл, `server/services/strategyEngine/`). Запрещено: пересказ формул в `server/`, выдуманные/оценочные уровни, параллельный трек-рекорд. Журнал браузера (`SignalsAuditLedger`, localStorage) — отдельный локальный журнал, он не синхронизирован с БД |
| 5 | Новые биржи (OKX spot, Bybit spot, Gate, etc.) | Scope ограничен Binance + KuCoin + derivatives |
| 6 | MVRV, NUPL, SOPR, on-chain метрики | Нет бесплатного API; отдельный трек |
| 7 | Макро-календарь (CPI, FOMC, NFP) | Отдельный трек; не рыночные данные |
| 8 | Общий API котировок и произвольный proxy | Разрешены только узкие same-origin GET routes `/api/market/*` для фиксированных публичных Binance/KuCoin REST endpoints (CORS gateway; allowlist + ограничения параметров + rate limit). Сервер НЕ источник котировок: рыночные данные движок стратегий тянет напрямую с публичного Binance REST (кэш + лимиты), а не через универсальный прокси. `GET /api/signals` — чтение собственной БД (только то, что опубликовало ядро), не прокси и не «общий API сигналов» для внешних потребителей. |
| 9 | Торговое исполнение (ордера, позиции), автоисполнение сигналов | Только чтение публичных данных; нет API-ключей; сигналы — наблюдения для человека |
| 11 | «Улучшение» правил архивных стратегий в LIVE-движке | LIVE вызывает frozen-функции архива; любое расхождение с раннером — баг LIVE, а не повод править стратегию |
| 10 | Скрейперы (парсинг HTML) | Только официальные REST/WS API |

## Подходы

| # | Не делать | Почему |
|---|-----------|--------|
| 1 | Silent fallback от реальных данных к хардкоду | Нарушает RULES §1 (честность данных) |
| 2 | `Math.random()` в бизнес-логике | Детерминированность; воспроизводимость |
| 3 | Демо-данные под видом реальных (`isDemo: false` на синтетике) | Нарушает RULES §3 |
| 4 | Оценочные суммы вместо «нет данных» | 0 ≠ null/unavailable |
| 5 | Новые market-data features без отдельного assignment | Scope creep prevention |
| 6 | ~76 REST запросов на Overview | Bulk ticker + lazy enrichment |
| 7 | Платные API | Бесплатные публичные endpoints only |
| 8 | Новые коммиты без реальных изменений | Git hygiene |
