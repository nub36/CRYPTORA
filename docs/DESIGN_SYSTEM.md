# DESIGN_SYSTEM — Дизайн-система CRYPTORA

> **Стиль:** Professional Dark Trading Terminal  
> **Философия:** Высокая информационная плотность (Data Density), максимальная читаемость цифр, отсутствие визуального шума и украшательств.

---

## 1. Цветовая палитра и семантика

В финансовом терминале цвет — это не декорация, а инструмент немедленной передачи статуса и риска.

### Базовые фоны и поверхности
- **Background Root (`bg-root`):** `#0a0d14` — глубокий ультратёмный графитово-синий фон.
- **Surface / Panel (`bg-surface`):** `#111622` — основной фон карточек, виджетов и таблиц.
- **Surface Hover (`bg-surface-hover`):** `#182030` — состояние наведения для строк и кнопок.
- **Border Default (`border-default`):** `#1e293b` — тонкие строгие границы разделов (1px).
- **Border Active (`border-accent`):** `#334155` — активный фокус, выделение строки.

### Семантические цвета
- **Зеленый (Bullish / Long / Positive):** `#10b981` (Emerald-500)
  - Используется строго для: прироста цены, положительного PnL, покупок, лонг-ликвидаций при закрытии шортов.
  - Текстовый аналог: `#34d399` (для читаемости на тёмном фоне).
  - Фоновый бейдж: `rgba(16, 185, 129, 0.12)`.
- **Красный (Bearish / Short / Negative):** `#ef4444` (Red-500)
  - Используется строго для: падения цены, отрицательного PnL, продаж, коротких позиций, рисков ликвидации.
  - Текстовый аналог: `#f87171`.
  - Фоновый бейдж: `rgba(239, 68, 68, 0.12)`.
- **Голубой / Циан (Information / Neutral Metrics):** `#38bdf8` (Sky-400)
  - Используется для открытого интереса, объемов, информационных меток и вспомогательных графиков.
- **Янтарный / Желтый (Warning / Extreme Attention):** `#f59e0b` (Amber-500)
  - Используется для предупреждений, экстремального фандинга, плашки «ДЕМОНСТРАЦИОННЫЕ ДАННЫЕ».
- **Фиолетовый (Derivatives / Radar / Analytics):** `#8b5cf6` (Violet-500)
  - Используется для акцентов в деривативах, событиях радара и аналитических модулях.
- **Нейтральный серый:**
  - Текст заголовков: `#f8fafc` (Slate-50)
  - Основной текст данных: `#cbd5e1` (Slate-300)
  - Вспомогательный текст / подписи колонок: `#64748b` (Slate-500)

> **Доступность (A11y / Не зависеть только от цвета):**  
> Любое числовое изменение сопровождается явным математическим знаком (`+` или `-`), либо текстовым маркером/стрелкой (`▲` / `▼`), чтобы пользователи с нарушением цветовосприятия могли однозначно считывать данные.

## 2. Типографика и форматирование чисел

- **Шрифт интерфейса:** Inter, system-ui, -apple-system, sans-serif.
- **Шрифт чисел и котировок:** Моноширинный шрифт (`font-mono` / JetBrains Mono / SFMono-Regular) с включенным табличным выравниванием цифр (`tabular-nums`).
- **Размеры шрифтов:**
  - `text-xs` (11–12px) — метки осей, тикеры, метаданные, бейджи.
  - `text-sm` (13–14px) — ячейки таблиц, значения параметров, навигация.
  - `text-base` (15–16px) — заголовки панелей, акцентные цены.
  - `text-xl` – `text-2xl` (20–24px) — ключевые цифры карточек (Market Cap, BTC Price).
  - Запрещен нечитаемый микрошрифт (мельче 10px).

---

## 3. Таблицы высокой плотности (Data Tables)

- Компактный вертикальный отступ строк (`py-2` или `py-2.5`).
- Липкая шапка (`sticky top-0`) с непрозрачным фоном для комфортной прокрутки.
- Числовые столбцы всегда выравниваются **по правому краю** (`text-right`), текстовые — по левому.
- Четкие монохромные разделители строк.
- Интерактивный hover с мягким подсвечиванием строки.

---

## 4. Контрольные точки адаптивности (Responsive Breakpoints)

- **Mobile (390px – 640px):** Скрываются второстепенные колонки таблиц (оставляем Asset, Price, 24h %, Mini Sparkline). Навигация сворачивается в компактное меню.
- **Tablet (768px – 1023px):** Двухколоночный макет на главной, таблицы содержат 6–7 основных колонок.
- **Desktop (1024px – 1439px):** Полноценный терминальный макет, мульти-колонки.
- **Wide Desktop (1440px – 1920px+):** Максимальное расширение рабочих зон, одновременный просмотр графиков, ленты радара и снапшотов деривативов.
