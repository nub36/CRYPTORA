# MONETIZATION — Архитектурная модель монетизации

> **ПРАВИЛО:** Платежи и биллинг на Этапе 1 **НЕ реализуются**. В документе фиксируется концептуальное разделение уровней доступа.

---

## 1. Тарифные планы (Tiers)

### 1.1. FREE (Базовый доступ)
- Полный обзор рынка (Overview).
- Базовые страницы монет с графиками и стандартными индикаторами.
- Базовая таблица рынка и фьючерсов (с небольшой задержкой или базовым срезом).
- Базовые калькуляторы размера позиции и PnL.
- Ограниченный скринер (до 3 одновременных фильтров).
- Ненавязчивая маркированная спонсорская аналитика.

### 1.2. PRO (Для активных трейдеров)
- Расширенный скринер без ограничений на количество условий.
- Сохранение пользовательских пресетов скринера.
- Персональные алерты через Telegram / Webhooks.
- Глубокие деривативные метрики: историческая динамика OI, тепловая карта ликвидаций.
- Расширенная лента Market Radar в реальном времени.

### 1.3. RESEARCHER / QUANT (Для аналитиков, количественных исследователей и фондов)
- Strategy Lab: визуальный и скриптовый конструктор правил и аналитических гипотез.
- Модуль честного бэктестинга на чистых исторических данных (математическая симуляция).
- Доступ к REST и WebSocket API терминала для получения рыночных данных.
- Экспорт исторических срезов данных в CSV/Parquet.
- *Примечание:* Ни один тариф не включает и не предоставляет функций торгового исполнения сделок.

---

## 2. Этика монетизации
- **Никакой продажи фальшивых сигналов:** CRYPTORA не продает «платные сигналы с гарантированной прибылью».
- **Честная маркировка партнерских материалов:** Любые рекламные или партнерские интеграции бирж обязаны содержать явный бейдж `Sponsored / Partner`.

---

## Состояние реализации (v0.8.39)
- Биллинг не подключён (решение владельца — отложить); модал тарифов содержит явное уведомление, переключение плана — предпросмотр.
- Партнёрские слоты: `content/sponsor-slots.json` → `SponsorSlot` (три позиции), бейдж «Sponsored / Partner» обязателен и не отключается,
  `rel="sponsored"`, только https, окно дат, фильтр обещаний доходности. Внешние ad-сети/трекеры не подключаются.
