# Статьи владельца (/articles)

Файлы `*.md` в этой папке публикуются на странице `/articles` при сборке. Файлы с префиксом `_` игнорируются.

Формат:

```
---
title: Заголовок
date: 2026-09-17
author: CRYPTORA
summary: Одно-два предложения для карточки списка.
tags: методология, ликвидации
sponsored: false
---

# Заголовок
Текст в markdown: абзацы, ##/### подзаголовки, списки, > цитаты, ``` код, **жирный**, *курсив*, `код`, [ссылка](https://…).
```

Правила (AGENTS.md / docs/MONETIZATION.md): без обещаний доходности, без торговых рекомендаций, без выдуманных цифр
(любая цифра — со ссылкой на источник). Партнёрский/рекламный материал обязан иметь `sponsored: true` — он получит бейдж «Sponsored / Partner».
Raw-HTML не рендерится.
